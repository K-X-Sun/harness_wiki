# AutoGPT

Autonomous AI agent built on top of the LangChain framework.

- GitHub: https://github.com/Significant-Gravitas/AutoGPT
- Stars: 100,000+ | Language: Python | License: MIT
- Dimension: Harness
- Project Type: Autonomous AI agent

## Overview

AutoGPT is an experimental open-source application showcasing the capabilities of modern LLMs. It demonstrates how agents can be used to accomplish complex tasks through iterative planning and tool usage.

## Architecture

Built on LangChain with:
- LLM-powered reasoning and planning
- Tool usage for web browsing, file operations, and more
- Memory for retaining information across tasks

## Status

This repository is in maintenance mode. The project has inspired many downstream implementations and has been a foundational project in the AI agent space.

## Related Projects

- [Agent-6](https://github.com/Significant-Gravitas/Agent-6): Next generation agent framework
- [AutoGPT Cloud](https://github.com/Significant-Gravitas/AutoGPT-Cloud): Cloud deployment infrastructure

## Usage

AutoGPT is designed to be a starting point for building custom AI agents. Users can:
- Configure agents with custom prompts
- Add custom tools and integrations
- Modify the planning and reasoning logic
