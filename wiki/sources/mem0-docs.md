# Mem0 Documentation

Welcome to Mem0 - Universal, Self-improving memory layer for LLM applications.

- Website: https://mem0.ai
- GitHub: https://github.com/mem0ai/mem0
- Dimension: Memory

## Overview

Mem0 provides a universal memory layer for LLM applications that can be self-improving over time. It enables developers to build applications with persistent, personalized memory for AI interactions.

## Platform Components

### Mem0 Platform
Managed memory with production-scale infrastructure, ready in minutes. Features:
- Automatic updates and analytics
- Enterprise security
- Managed service option

### Mem0 Open Source
Self-host the Mem0 stack for full control over data, deployment, and customization.

### Cookbooks
Production-ready tutorials that show how to ship memorable AI experiences.

### Integrations
Connect Mem0 to LangChain, CrewAI, Vercel AI SDK, and 20+ partner frameworks.

### Agent Plugins
Specific integrations for Claude Code and other agent platforms.

### API Reference
Explore every REST endpoint with payload examples and usage guidance.

### CLI
Manage memories directly from your terminal. Built for developers and AI agents.
