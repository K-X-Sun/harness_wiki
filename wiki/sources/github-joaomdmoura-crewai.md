# CrewAI

Framework for orchestrating role-playing, autonomous AI agents.

- GitHub: https://github.com/crewAIInc/crewAI
- Stars: 48.9K | Language: Python | License: MIT
- Dimension: Harness
- Project Type: Multi-agent framework

## Overview

CrewAI is a lean, lightning-fast Python framework built entirely from scratch - completely independent of LangChain or other agent frameworks. It empowers developers with both high-level simplicity and precise low-level control for creating autonomous AI agents.

## Key Components

### CrewAI Crews
Teams of AI agents with true autonomy and agency, working together to accomplish complex tasks through role-based collaboration:
- Natural, autonomous decision-making between agents
- Dynamic task delegation and collaboration
- Specialized roles with defined goals and expertise
- Flexible problem-solving approaches

### CrewAI Flows
Production-ready, event-driven workflows that deliver precise control over complex automations:
- Fine-grained control over execution paths
- Secure, consistent state management
- Clean integration of AI agents with production Python code
- Conditional branching for complex business logic

## AMP Suite

Enterprise-ready AMP Suite with Crew Control Plane:
- **Tracing & Observability**: Real-time monitoring and tracking
- **Unified Control Plane**: Centralized platform for managing agents
- **Seamless Integrations**: Connect with existing enterprise systems
- **Advanced Security**: Robust security and compliance
- **Actionable Insights**: Real-time analytics and reporting
- **24/7 Support**: Dedicated enterprise support
- **Deployment Options**: On-premise or cloud
