# OpenHands

AI-Driven Development framework with SDK, CLI, and Cloud deployment.

- GitHub: https://github.com/OpenHands/OpenHands
- Stars: 71,200 | Language: Python/TypeScript | License: MIT
- Paper: arXiv:2511.03690
- Dimension: Harness
- Project Type: AI-driven development platform

## Overview

OpenHands is a framework focused on AI-driven development. It provides multiple interfaces for working with AI agents, from CLI to enterprise cloud deployments.

## Components

### OpenHands Software Agent SDK
Composable Python library containing all agentic tech. Powers everything else below.

### OpenHands CLI
Easiest way to start using OpenHands. Familiar experience like Claude Code or Codex. Power with Claude, GPT, or any LLM.

### OpenHands Local GUI
Run agents on your laptop with REST API and React application. Familiar experience like Devin or Jules.

### OpenHands Cloud
Hosted infrastructure deployment with:
- Integrations with Slack, Jira, Linear
- Multi-user support
- RBAC and permissions
- Collaboration features

### OpenHands Enterprise
Self-hosted in VPC via Kubernetes with:
- Source-available features
- Extended support
- Access to research team
